1Paste the document content

Best result: copy from the original Google Doc or Word file. Headings, lists, tables, bold and links are then taken exactly as in the document.

Got a PDF or Word file? Upload it instead. The file keeps its links and heading levels, but copied text does not.
How to add this to WordPress
  1. Click Copy code.
  2. Open the post. Click the three dots at the top right and choose Code editor. (Classic editor: use the Text tab.)
  3. Paste the code. WordPress makes a paragraph from each block of text separated by a blank line.
  4. Add the title, slug and SEO fields from the SEO fields box, then publish.
